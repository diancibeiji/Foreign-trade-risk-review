# Foreign-trade-risk-review

中小外贸企业政策风险体检表展示空间。

**在线预览：** https://diancibeiji.github.io/Foreign-trade-risk-review/

## 这是什么

广州大学第二十届“挑战杯”大学生课外学术科技作品竞赛参赛作品《国际外贸政策变动下我国外贸型企业的困境识别与“预报式”预警服务体系研究》的说明页。

把定性的“政策影响”转成可比较、可复算的分数：16 项指标、2 个维度、4 级预警。企业填报一次，得到 1—10 分评级、最薄弱的模块，以及对应的改进动作。

## 页面结构

| 章节 | 内容 |
| --- | --- |
| 概览 | 输入 / 输出 / 依据 |
| 01 背景 | 政策变动的三类冲击 |
| 02 调研 | 五步路径与样本规模 |
| 03 发现 | 四组关键数据 |
| 04 模型 | 16 项指标权重与四级区间 |
| 附 试算 | 可交互的风险自评演示 |
| 05 验证 | 两家企业的诊断对比 |
| 06 施策 | 分级干预策略 |
| 07 成果 | 调研报告、论文与模型 |

## 技术说明

- 单文件 `index.html`，无外部依赖，不加载任何 CDN
- 可直接双击打开，也可用页面右上角「打印」导出 PDF（内置打印样式）
- 交互试算为纯前端计算，不收集任何数据

## 主要数据

- 有效问卷 2,376 份（发放 2,758 份，回收率 86.14%）
- 深度访谈 237 人，走访企业 68 家，访谈文本 14.9 万字
- 专家研判 32 位（指标筛选）、35 位（权重测算）
- 覆盖广东 11 个外贸重点城市

## 说明

页面内容依据项目结题报告书、调研报告与访谈记录整理，企业原话经整理并隐去受访者姓名。仅用于项目说明，不构成投资或合规建议。
